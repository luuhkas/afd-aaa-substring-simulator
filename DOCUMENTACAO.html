1.4 Semântica dos Estados

q0
Estado inicial — nenhum 'a' consecutivo acumulado
q1
Leu exatamente 1 'a' consecutivo
q2
Leu exatamente 2 'a' consecutivos
q3 ★
Estado final — encontrou "aaa". Toda extensão é aceita.
Invariante: q3 é um estado de absorção. Qualquer símbolo lido em q3 mantém o autômato em q3.

1.5 Diagrama de Transições

         b              b              b
    ┌──────┐       ┌──────┐       ┌──────┐
    ↓      │       ↓      │       ↓      │
→  [q0] ──a──→ [q1] ──a──→ [q2] ──a──→ ((q3))
    ↑      │    │           │               │ a,b
    └──────┘    └───b───────┘               └──┘
→ estado inicial  ·  (()) estado final

1.6 Prova de Correção

Teorema: M aceita w ↔ w contém "aaa".
  • (→) Se w contém "aaa", δ percorre q0→q1→q2→q3 no ponto da ocorrência. q3 é armadilha: qualquer sufixo mantém o estado. Logo w é aceita.
  • (←) Se M aceita w, o estado final é q3. O único caminho até q3 é via (q2, a)→q3, que exige q1→q2 antes, logo q0→q1→q2→q3 — três 'a' consecutivos ocorreram.

2.1 config.py — Estruturas de Dados

Toda a definição matemática do AFD vive aqui como estruturas Python nativas:

TRANSICOES = {
    ("q0", "a"): "q1",  ("q0", "b"): "q0",
    ("q1", "a"): "q2",  ("q1", "b"): "q0",
    ("q2", "a"): "q3",  ("q2", "b"): "q0",
    ("q3", "a"): "q3",  ("q3", "b"): "q3",
}

δ é um dicionário (estado, símbolo) → estado. Consulta em O(1).

Constantes de temporização que controlam o ritmo da simulação:

2.3 Ciclo de Execução — Modo Manual

ENTER pressionado ↓ iniciar_execucao(agora) estado_atual = "q0", indice = 0, executando = True ↓ Loop 60 FPS → atualizar(agora): ┌─ animacao is None → _iniciar_proxima_transicao() │ simbolo = palavra[indice] │ destino = TRANSICOES[(estado_atual, simbolo)] │ animacao = { origem, simbolo, destino, inicio } └─ animação em curso → aguarda 1050ms ↓ tempo esgotado estado_atual = destino visitados.add(estado_atual) indice += 1, animacao = None ↓ indice == len(palavra) → resultado = "ACEITA" se estado_atual == "q3" senão "REJEITA"

2.4 Ciclo de Execução — Modo Arquivo (Auto-play)

carregar_arquivo(caminho) lê linhas → fila = ["aaab", "baaab", ...] indice_fila = 0 → _carregar_palavra_atual() ↓ atualizar(agora) — verificações por ordem: if concluido → return ← congela tudo [AGUARDANDO INÍCIO] tempo_carregado is None → registra timestamp elapsed >= 400ms → iniciar_execucao(agora) [EXECUTANDO] — mesmo ciclo do modo manual [RESULTADO EXIBIDO] tempo_resultado is None → registra timestamp → historico.append((palavra, resultado)) elapsed >= 1100ms → avancar_fila() ├─ tem próxima → _carregar_palavra_atual() → repete └─ última → concluido = True
PESSOA 3
Geometria e Animação
geometry.py — Bézier · easing · interpolação de cores · cabeça de seta

3.1 Responsabilidade do Módulo

geometry.py calcula onde e como os elementos se movem. Não renderiza nada — devolve apenas pontos e cores para ui.py usar.

3.2 Curva de Bézier Cúbica

Cada aresta do diagrama é uma curva paramétrica com 4 pontos de controle:

B(t) = (1-t)³P₀ + 3(1-t)²tP₁ + 3(1-t)t²P₂ + t³P₃,  t ∈ [0,1]

caminho_transicao(origem, simbolo) seleciona P1 e P2 por tipo:

TransiçãoCurvatura
Transições a (q0→q1, q1→q2, q2→q3)Arco suave para frente
b de q1 → q0Arco médio abaixo
b de q2 → q0Arco largo abaixo
q0→q0 e q3→q3 (self-loops)Loop sobre o próprio estado

3.3 Função de Easing (smoothstep)

ease(t) = t² · (3 − 2t)

Aplicada sobre t antes de localizar o token na curva. O token parte devagar, acelera no meio e desacelera no fim — movimento natural ao olho humano.

3.4 Localização do Token na Curva

ponto_no_caminho(pontos, t): divide a curva em segmentos, calcula o comprimento total e percorre até a fração ease(t):

alvo = ease(t) * comprimento_total
# percorre segmentos somando comprimentos até atingir alvo
# interpola linearmente dentro do segmento final

3.5 Cabeça de Seta

pontos_cabeca_seta(fim, anterior, tamanho=13) usa trigonometria:

angulo  = atan2(fim.y - anterior.y, fim.x - anterior.x)
ponta_1 = fim - tamanho · (cos(angulo - 0.48), sin(angulo - 0.48))
ponta_2 = fim - tamanho · (cos(angulo + 0.48), sin(angulo + 0.48))

3.6 Interpolação Linear de Cores

misturar(cor_a, cor_b, t) = cor_a + (cor_b − cor_a) · t

Usada para animar o fundo dos estados durante a transição — origem e destino pulsam suavemente enquanto o token se move.

4.1 Visão Geral da Arquitetura

Lógica pura do AFD — independente de Pygame e de UI

4.3 Loop Principal (60 FPS)

while True:
    focado = processar_eventos(automato, focado, seletor, registro)
    automato.atualizar(pygame.time.get_ticks())
    interface.desenhar(automato, focado, seletor, registro["scroll_x"])
    pygame.display.flip()
    clock.tick(60)

Cada frame: captura eventos → avança estado → renderiza → exibe na tela.

4.4 Hierarquia de Prioridade de Eventos

processar_eventos(): 1. QUIT → pygame.quit() + sys.exit() 2. concluido → apenas botões da tela de conclusão → continue 3. seletor.aberto → hover / clique em linha / ESC → continue 4. drag registro → MOUSEBUTTONUP, MOUSEMOTION 5. modo normal → clique no botão arquivo / campo de texto 6. KEYDOWN → ESC, ENTER, BACKSPACE, setas, a/b

Cada camada usa continue para ignorar os eventos que não lhe pertencem.

4.5 Scroll do Registro

_clamp_scroll(automato, registro):
    visivel    = LARGURA_CANVAS - 32          # 716 px visíveis
    total      = len(fila) * BADGE_REGISTRO_W # n × 120 px
    max_scroll = max(0, total - visivel)
    scroll_x   = clamp(scroll_x, 0, max_scroll)

Se total ≤ visivel: badges centralizados, sem scroll. Se total > visivel: drag horizontal ativo, scrollbar exibida.

4.6 Fluxo Completo End-to-End

Inicialização → modo manual [MODO MANUAL] Digita a/b → ENTER → animação passo a passo → resultado ↓ Clica "Abrir arquivo" [SELETOR] Lista .txt do diretório do script Clica arquivo → carregar_arquivo(caminho) ↓ [MODO ARQUIVO — AUTO-PLAY] Para cada sentença na fila: pausa 400ms → executa com animação passo a passo → exibe resultado → pausa 1100ms → badge: âmbar (atual) → verde/vermelho (processado) ↓ Última sentença concluída → concluido = True [TELA DE CONCLUSÃO] Resumo: N aceitas / M rejeitadas [ Reiniciar simulador ] → _reset() → volta ao modo manual [ Fechar simulador ] → sys.exit()
